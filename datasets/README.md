# SeeBeyond Datasets

Medical datasets are kept locally and are not uploaded to GitHub.

## Datasets

### APTOS 2019
Used for Diabetic Retinopathy severity classification (Grades 0-4).

### IDRiD
Used for lesion segmentation, localization and disease grading.

### DRIVE
Used for retinal blood-vessel segmentation.

### Messidor-2
Used for independent/external validation of the DR classifier.
